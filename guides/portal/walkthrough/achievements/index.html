Portal walkthrough · Appendices

Achievements

Spoilers. This page shows everything in it, puzzle solutions included, and sometimes points ahead to later chambers.

Every achievement in Portal, grouped by how you earn it. Each entry names the chapter where it happens, so you can jump back to it.

Progression

Every player who reaches the point gets these on the default path.

Lab Rat

ID lab_rat; not hidden; type: progression.

Trigger: pick up the orange portion of the portal gun (the fully powered dual-portal gun) in Test Chamber 11.

Not missable. There is no point-of-no-return window (unmissable on normal play), and it has no prerequisites.

Fratricide

ID fratricide; not hidden; type: progression.

Trigger: incinerate the Weighted Companion Cube in the Incinerator at the end of Test Chamber 17. This is required to open the exit.

Not missable. There is no point-of-no-return window (it is required to advance), and it has no prerequisites.

Partygoer

ID partygoer; not hidden; type: progression.

Trigger: escape the fire pit with portals, reaching the ledge or platform above it, at the end of Test Chamber 19 (“make the correct party escort submission position decision”).

Not missable. There is no point-of-no-return window (unmissable), and it has no prerequisites.

Heartbreaker

ID heartbreaker; not hidden; type: progression.

Trigger: destroy GLaDOS by incinerating the final core in the escape and boss fight in Escape Sequence / Surface Finale. That completes the game.

Not missable. There is no point-of-no-return window (it marks completion). The prerequisite is to reach the boss.

Mastery

A skill, or a restriction you accept, beyond normal play.

Completing the game (Heartbreaker) unlocks Advanced Chambers (these feed Cupcake, Fruitcake and Vanilla Crazy Cake) and Portal Challenges (these feed Basic Science, Rocket Science and Aperture Science). None of these six achievements is accessible on a first run.

Long Jump

ID long_jump; not hidden; type: mastery.

Trigger: travel 300 feet in a single jump or fling. It is best done in the large escape-sequence room with the muddy trench, in Escape Sequence / Surface Finale.

Not missable. There is no point-of-no-return window. The prerequisite is the dual-portal gun from Test Chamber 11.

Cupcake

ID cupcake; not hidden; type: mastery.

Trigger: beat 2 of the 6 Advanced Test Chambers (Advanced 13-18).

Not missable. There is no point-of-no-return window. The prerequisite is to complete the main game, which unlocks the Advanced Chambers.

Fruitcake

ID fruitcake; not hidden; type: mastery.

Trigger: beat 4 Advanced Test Chambers.

Not missable. There is no point-of-no-return window. The prerequisite is to complete the main game.

Vanilla Crazy Cake

ID vanilla_crazy_cake; not hidden; type: mastery.

Trigger: beat all 6 Advanced Test Chambers (Advanced 13-18).

Not missable. There is no point-of-no-return window. The prerequisite is to complete the main game.

Basic Science

ID basic_science; not hidden; type: mastery; genre: mission.

Trigger: earn bronze medals on all 18 Challenge tasks (Chambers 13-18, each with least portals, least steps and least time).

Not missable. There is no point-of-no-return window. The prerequisite is to complete the main game, which unlocks Portal Challenges.

Rocket Science

ID rocket_science; not hidden; type: mastery; genre: mission.

Trigger: earn silver medals on all 18 Challenge tasks.

Not missable. There is no point-of-no-return window. The prerequisite is to complete the main game.

Aperture Science

ID aperture_science; not hidden; type: mastery; genre: mission.

Trigger: earn gold medals on all 18 Challenge tasks. Note that sv_cheats and no-clip disable medal submission, so earn them legitimately.

Not missable. There is no point-of-no-return window. The prerequisite is to complete the main game.

Collection

A finite, enumerable set, completed in full.

Camera Shy

ID camera_shy; not hidden; type: collection.

Trigger: detach all 33 security cameras with the portal gun, getting every camera the first time through each chamber (Chambers 02, 03, 04, 05, 10, 11, 13, 15, 16, 17, 18, 19).

Missable: yes. The counter resets if you skip or replay a chamber. The latest camera is in Test Chamber 19, and there are none after. The prerequisite is the dual-portal gun, for most cameras.

All 33 set members are listed in Items and objects.

The common claim that interrupting GLaDOS’s camera voice lines breaks this achievement is false. The detach counter and the voice-line counter are separate.

No cameras exist in Escape Sequence / Surface Finale or after. Collect all Test Chamber 19 cameras (3) before the fire pit (gate 6). Moving on to Escape Sequence / Surface Finale at gate 7 is the final point of no return. Skipping or replaying a chamber resets the counter. †

Transmission Received

ID transmission_received; hidden: unknown. It is listed on Steam by name with the placeholder description “..?”, and the sources checked state no hidden flag. Type: collection.

Trigger: collect all 26 hidden radios and bring each to its signal spot, where the light turns green.

Not missable. There is no point-of-no-return window. The prerequisite is to complete the game once: the radios other than the Test Chamber 00 one only appear after a full completion.

All 26 set members are listed in Items and objects.

Radios other than the Test Chamber 00 one do not exist until the game is completed once, so plan a dedicated post-completion radio run.

Threshold

A cumulative count, without a finite-set ceiling.

Terminal Velocity

ID terminal_velocity; not hidden; type: threshold.†

Trigger: fall 30,000 feet. In any test chamber where you can put portals on both the ceiling and the floor, place one above and one below you, jump in and wait about 5 minutes.†

Not missable: it is doable in any chamber with facing portalable ceiling and floor. There is no point-of-no-return window. The prerequisite is the dual-portal gun from Test Chamber 11.

Discovery

Found by deliberate exploration of a non-obvious interaction.

Friendly Fire

ID friendly_fire; not hidden; type: discovery.

Trigger: pick up one turret and use it to physically knock over another turret. It is easiest in Test Chamber 16, which is turret-dense; turrets also appear in Test Chamber 18 and in the escape.

Not missable: turrets keep appearing after Test Chamber 18 (a three-turret ambush in Escape 01, a turret arena in Escape 02), so leaving it does not lock the achievement out. The prerequisite is to reach a turret chamber, such as Test Chamber 16.

† Only one source reports this.
